# Database reference material

This folder contains schema proposals, ER notes, database-specific scripts, and connection/migration documentation. The active Laravel migration source remains in `backend/database/migrations/`. The v4.1 SQL snapshot is duplicated here for convenient review while its original backend copy remains available to Laravel tooling.

`schema/` contains the prior `data/schema/` contents, including proposal versions and constraint test scripts. No live database files, backups, or credentials belong here.
