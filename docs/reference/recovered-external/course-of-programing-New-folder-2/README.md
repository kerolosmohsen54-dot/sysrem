# تشغيل نسخة Precision Slate ERP التجريبية محليًا

هذه نسخة عرض محلية مبنية على ملف HTML الحالي. لا تتصل بقاعدة بيانات أو بخدمات خارجية، وتُحفظ التغييرات في `localStorage` داخل المتصفح الذي تستخدمه. هذه الآلية للعرض والتجربة فقط وليست تخزينًا آمنًا أو بديلًا عن قاعدة بيانات إنتاجية.

## متطلبات التشغيل

- Windows 10 أو أحدث.
- Python 3 مع مشغّل `py` (لا توجد مكتبات Python أو JavaScript إضافية مطلوبة).
- متصفح حديث مثل Edge أو Chrome.

## بدء التشغيل

1. فك ضغط/افتح مجلد المشروع على جهازك.
2. انقر مرتين على `start-demo.bat`.
3. يفتح النظام تلقائيًا على العنوان:
   `http://127.0.0.1:8000/precision-slate-erp-final__5_%20%281%29.html`
4. يعمل الخادم في نافذة مصغّرة منفصلة؛ اتركها مفتوحة طوال وقت العرض. لإيقاف الخادم أغلق نافذته.

يمكن أيضًا تشغيله يدويًا من PowerShell داخل مجلد المشروع:

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1
```

ثم افتح الرابط أعلاه. لإيقاف الخادم اليدوي اضغط `Ctrl+C`. لا تفتح ملف HTML من جهاز آخر؛ الخادم مربوط بعنوان loopback ولا يستمع إلى الشبكة الخارجية.

## الدخول

- اسم المستخدم: `Admin`
- كلمة المرور: `Demo123`

## البيانات المحلية والنسخ الاحتياطي

- يبدأ النظام دون سجلات عملاء أو منتجات أو موردين أو فواتير أو طلبات أو حركات، وتبدأ أرصدة الخزائن بصفر. أضف بياناتك التجريبية من النماذج عند الحاجة.
- بيانات الدخول المحلية `Admin` / `Demo123` باقية لفتح التطبيق؛ حذف سجلات العرض لا يلغي شاشة الدخول.
- تستمر البيانات المحفوظة في ملف تعريف المتصفح نفسه بعد إعادة تحميل الصفحة وإغلاقه وفتحه مجددًا.
- من **الإعدادات العامة ← النسخ الاحتياطي** يمكن تنزيل ملف JSON لاستعادة نسخة البيانات لاحقًا، أو استيراد نسخة سبق تنزيلها.
- زر **إعادة بيانات العرض** يحذف البيانات المحلية ويعيد النظام إلى حالة البداية الفارغة. لا تستخدمه قبل تنزيل نسخة إذا أردت الاحتفاظ بتجاربك.
- التخزين مرتبط بعنوان الموقع والمتصفح. مسح بيانات الموقع أو استخدام متصفح/ملف تعريف مختلف يعني عدم ظهور التغييرات السابقة.

## الوظائف التي تعمل في النسخة المحلية

- الدخول التجريبي والتحقق من بياناته.
- تسجيل المشتريات مع التحقق من البنود، تحديث رصيد المنتج والخزينة عند الدفع، وإضافة الحركة إلى السجل.
- إنشاء أوامر شراء محلية متعددة البنود كمسودة أو كأمر مسجل محليًا؛ يمكن تسجيل فاتورة شراء مرتبطة بها على دفعات، مع تحديث حالة الاستلام الجزئي/الكامل والتحقق من المورد وكميات الأمر. التسجيل لا يرسل الأمر إلى المورد.
- اعتماد تسوية مخزون مع التحقق من الكميات وسبب التسوية، وإظهار الحركة وتحديث الرصيد.
- إنشاء طلب بيع كمسودة أو مؤكد، وإنشاء فاتورة بيع/مسودة وربطها باسم العميل وبنودها؛ الفاتورة الصادرة تخصم رصيد المنتج المحلي إذا كان بندها مطابقًا لمنتج مسجل ومتوفرًا.
- إنشاء إذن تسليم لطلب محلي مؤكد، وتسجيل التسليم الجزئي أو الكامل مع منع تجاوز الكمية المطلوبة أو رصيد المستودع وتحديث حركة المخزون وحالة الطلب. نوع «توصيل فقط» يسجل التسليم دون حركة صرف.
- تسجيل تحصيل على فاتورة محددة، تحديث المدفوع والمتبقي ورصيد الخزينة، ورفض مبالغ التحصيل غير الصحيحة أو الأكبر من المتبقي.
- تسجيل مصروف وتحديث رصيد الخزينة.
- إضافة العملاء والمنتجات والموردين والمستودعات، وتعديل بعض حقول سجلات العرض وحالات الطلبات المحلية وحذف السجلات الجديدة مع حماية العلاقات والأرصدة.
- تسجيل الحاويات وربطها بمورد ومنتجات ومستودع، وتحديث حالتها، واستلامها على دفعات مع منع تجاوز الكميات وتسجيل أسباب العجز عند الإنهاء؛ تُحدّث أرصدة المخزون وحركاته محليًا.
- احتساب التكلفة الواصلة للحاوية بعد إنهاء استلامها، وتوزيع الشحن والجمارك والتخليص بنسبة قيمة البضائع المستلمة، وتحديث متوسط تكلفة المنتج مرة واحدة.
- تنفيذ التحويلات بين الخزائن، وتخزين أسعار الصرف والإعدادات محليًا.
- البحث في بعض قوائم الجداول، وحفظ البيانات واستعادتها محليًا وتنزيل/استيراد نسخة احتياطية.

**حدود النسخة:** حجوزات المخزون ومرتجعات المبيعات والشراء ليست دورات مكتملة ولا تغيّر المخزون أو الأرصدة. التقارير وبعض صفحات التفاصيل ما زالت تعرض قوالب واجهة وليست تقارير محاسبية مبنية بالكامل على كل القيود. إدارة المستخدمين والصلاحيات لا تنشئ حسابات فعلية؛ بيانات الدخول التجريبية ثابتة. لا يوجد إرسال بريد أو رفع ملفات أو إضافة عملات جديدة أو تكامل ضريبي/دفع. أوامر الشراء والحاويات تعمل محليًا ولا ترسل للمورد أو تنشئ التزامات محاسبية إنتاجية. الفواتير المحلية تخصم المنتجات المسجلة من المخزون عند الإصدار، بينما بنود الخدمات غير المسجلة لا تُعامل كمخزون. توزيع التكلفة الواصلة طريقة عرض محلية مبسطة وليس معالجة محاسبية إنتاجية. أسعار العملات غير الأساسية تُترك فارغة حتى تدخل أسعارك.

## التحقق المنفذ

- حالة البداية فارغة؛ تُمسح البيانات المحلية القديمة من إصدار العرض السابق عند أول تشغيل لهذا الإصدار.
- تُفتح الوحدات الـ45 دون فشل في التنقل، ولم تظهر أخطاء JavaScript أو Console خلال اختبار التنقل.
- اختُبرت إضافة حاوية بمنتج ومورد، ورفض كمية استلام تتجاوز المتبقي، وتسجيل استلام جزئي، ورفض الإنهاء دون سبب للعجز، وإنهاء الاستلام مع تسجيل السبب، وتحديث رصيد المخزون وحركة الاستلام.
- اختُبر توزيع التكلفة الواصلة والتحقق من عدم تكرار تطبيقها، وبقاء الحاوية والاستلام والتكلفة بعد إعادة تحميل الصفحة.
- اختُبر إصدار فاتورة بعد رفض كمية تتجاوز المخزون، وتجميع كميات السطرين للمنتج نفسه لمنع صرف كمية أكبر من الرصيد، وتسجيل دفعة مرتبطة بالفاتورة وتحديث رصيد الخزينة؛ واختُبر تسجيل شراء آجل وتحديث الرصيد ومتوسط تكلفة المنتج.
- اختُبر حفظ البيانات بعد إعادة التحميل، ثم أُزيلت بيانات الاختبار من المتصفح وأُعيد فتح شاشة الدخول بحالة بيانات فارغة.
- استُخدم الخادم المحلي على `http://127.0.0.1:8000/` وتأكدت استجابة صفحة النظام بنجاح.

## ملاحظة الخصوصية

لا تدخل بيانات عملاء حقيقية أو كلمات مرور فعلية. البيانات محفوظة على جهازك في المتصفح ويمكن لأي شخص لديه وصول إلى ملف المتصفح رؤيتها؛ استخدم بيانات العرض فقط.
