# تقرير الموبايل

الحالة في 17 أكتوبر 2026: **الاختبارات والبناء البرمجي ناجحة؛ قبول Android الوظيفي النهائي ما زال ناقصًا**.

## المنجز حتى الآن

- التطبيق النشط React Native 0.87.1 وTypeScript موجود في `../mobile-app/`، وفيه تسجيل الدخول وقفل التطبيق والقنوات والوارد والإيداع اليدوي والإعدادات والتخزين المحلي وoutbox.
- يوجد مشروع Android وiOS؛ جمع الرسائل والتنبيهات خاص بـAndroid. iOS يقتصر على المشاهدة والإدخال اليدوي دون تحقق بمحاكي.
- واجهات API تشمل تسجيل الدخول، القنوات والرسائل والعملاء والإيداعات والسحوبات والمزامنة. راجع `../docs/mobile/RN_FINAL_REPORT.md` و`../docs/mobile/E2E_RN_REPORT.md`.

## فحوص هذه الجلسة

| الفحص | النتيجة |
|---|---|
| TypeScript (`npm run typecheck`) | PASS. |
| ESLint (`npm run lint`) | PASS — صفر أخطاء و163 تحذيرًا (تنسيقات inline، `void`، وbitwise وغيرها). |
| Jest (`npm test -- --runInBand`) | PASS بعد مواءمة توقع API: 12 suite و96 اختبارًا. |
| Android debug build (`gradlew assembleDebug`) | PASS — اكتمل باستخدام JDK 25 محليًا؛ ظهرت تحذيرات AGP/deprecated native API فقط. |
| تنظيف Android (`gradlew clean`) | PASS؛ توقفت بعدها Gradle daemon. |

## ما أُصلح أو نُظّف

- تحدّث توقع اختبار القنوات ليطابق مرشح `paused=0` الافتراضي الموجود بالفعل في `src/api/channels.ts`.
- بُني التطبيق بنجاح ثم نُظّفت مخرجات `build/` بواسطة Gradle؛ بقي مجلد Gradle المحلي `.gradle/` كذاكرة مؤقتة ولم يُحذف.
- لم تُنقل شيفرة التطبيق من `mobile-app/`: هناك مسارات تشغيل ومراجع قائمة، وبيانات AVD محلية حجمها نحو 8.2 GB. النقل قد يكسرها؛ مجلد `mobile/` الحالي يحوي هذا التقرير لتبقى المسارات الحالية سليمة.
- أُوقف ADB server. لا توجد بيانات AVD أو كلمات مرور أو إعدادات محلية حُذفت.
- فحص التطابق الحرفي لملفات المصدر غير الفارغة في `backend/app/` و`frontend/src/` و`mobile-app/src/` لم يجد نسخًا متطابقة. لا توجد قائمة مؤكدة أخرى لكود مكرر؛ لم يُحذف شيء.
- بقيت بيانات `.avd-e2e-home/` (نحو 8.2 GB)، و`.tmp/` التي فيها صور وسجلات وملفات إعداد/تجربة، وذاكرة `.gradle/`، و`.bundle/` و`.toolchain/` و`node_modules/` لأن بعضها حالة محاكي/تجربة محلية أو بيئة بناء غير مؤكدة المصدر. لم تُنظّف هذه المجلدات.

## المشاكل المعروفة

- لا يزال اختبار الأعمال على جهاز Android متصل بالخلفية غير متحقق في هذه الجلسة.
- ESLint يخرج 163 تحذيرًا؛ لم أغيّر تنسيقات جماعية.
- لاختبار تدفقات القنوات والتحصيل والسحب يلزم backend يعمل وحسابات اختبار وصلاحيات مطابقة.
- بعض الاعتماديات تبني مكتبات native؛ تحذيرات AGP تتعلق بواجهات قديمة، وليست فشلًا بحد ذاتها.

## التشغيل والاختبار

من `mobile-app/`:

```powershell
npm start
npm run typecheck
npm run lint
npm test -- --runInBand
npm run android
```

لبناء APK من `mobile-app/android/` بعد ضبط `JAVA_HOME`:

```powershell
.\gradlew.bat assembleDebug
```
