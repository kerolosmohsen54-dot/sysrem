## ما أُصلح أو نُظّف

- حُوّل `let allocatedGlobalDiscount` إلى `const` في `src/mocks/handlers.ts`؛ تغيير بلا أثر سلوكي أزال خطأ `prefer-const`.
- حُدّث توقع اختبار زر معاينة الفاتورة ليتطابق مع زر الشاشة الحالي، وأضيفت استجابة fixture كاملة لخيارات مُصدري الفواتير.
- `frontend/dist/` ناتج build تم توليده في هذه الجلسة؛ لم يُحذف بعد بسبب رفض أداة التنفيذ طلب الحذف الآلي. لم تُحذف ملفات مصدر.
- فحص التطابق الحرفي لملفات المصدر غير الفارغة في `backend/app/` و`frontend/src/` و`mobile-app/src/` لم يجد نسخًا متطابقة. لم يُحذف كود قديم أو مكرر.

## المشاكل المعروفة

- خطأ import غير مستخدم أعلاه ما زال قائمًا. لم أحذفه لأن التعليمات تمنع حذف أي كود.
- الاختبارات تطبع تحذيرات React Query عن بيانات حساب غير معرّفة في بعض fixtures؛ الاختبارات ذات الصلة نجحت.
- اختبارات الواجهة تعتمد على MSW ولا تثبت تدفقات الخادم أو قاعدة البيانات الحية.
- تحذيرات بيانات الرصيد وطلب MSW غير المعالج تستحق مراجعة منفصلة رغم نجاح المجموعة الكاملة.
- `debug.log` في جذر المشروع و`.b/` تركتهما لأن أصل الملفات ومحتوى scratch غير مؤكدين؛ لا توجد قائمة مؤكدة لشيفرات مكررة بعد فحص التطابق الحرفي.

## التشغيل والاختبار

من `frontend/`:

```powershell
npm run dev
npm run build
npm run typecheck
npm run lint
npm test
npm run contract:check
```

التطبيق يحتاج API محليًا للتشغيل المتصل؛ اختبارات Vitest تستخدم fixtures ولا تحتاج تشغيل خادم.
