## Web-only features — not needed by the app

Browser-cookie authentication and session administration, owner browser device administration, user/role/permission management, inventory and procurement, sales-document workflows, reports, audit-history browsing, and email-verification administration remain web/backend features. They are not part of this Android API gap scope and were not modified.
